# Lumen Circuit Studio

**The Next-Generation Open-Source Analog/Mixed-Signal EDA Suite**

Lumen Circuit Studio is a comprehensive EDA platform for custom IC design,
featuring schematic capture, symbol editing, layout editing, PDK management,
and an integrated Analog Design Environment (ADE) powered by the GSPICE simulator.

## Features
- **Schematic Editor** — Hierarchical schematic capture with wire routing
- **Symbol Editor** — Manual and auto-generated symbol creation  
- **Library Manager** — Cadence-like library/cell/view management
- **ADE** — Analog Design Environment with simulation setup
- **Waveform Viewer** — Interactive waveform display
- **PDK Manager** — Process Design Kit management
- **GSPICE Integration** — Built-in parallel circuit simulator

## Quick Start
```bash
python -m lumen
```
